# Skilly for Builders

> Skilly for Builders is an embeddable voice-and-pointer onboarding assistant for websites and SaaS products. A user asks a question out loud, Skilly answers from the product's own content, and an on-screen pointer shows the exact control to use next.

- Product type: Voice-guided product onboarding software
- Audience: SaaS teams, website owners, product teams, support teams, and customer-success teams
- Delivery: Embeddable web widget
- Installation: One script tag
- Management application: [Skilly Studio](https://studio.tryskilly.app/signup)
- Product page: https://tryskilly.app/
- Pricing: https://tryskilly.app/pricing.md

## What it does

Skilly for Builders gives users contextual assistance inside the product they are already using. It combines spoken questions, spoken answers, an answer history in a fixed widget, and a pointer that can move independently to the relevant interface element.

The assistant is taught from product content, documentation, URLs, or notes. Studio drafts the first project skill as editable Markdown. A team can review that content, configure allowed domains, preview the widget, publish it, and monitor usage.

## Typical use cases

1. Guide a new user through product setup and activation.
2. Answer "where do I click?" questions inside a SaaS interface.
3. Explain unfamiliar settings, dashboards, API keys, and workflows.
4. Deflect repetitive onboarding and support questions.
5. Provide open-ended guidance when a fixed product tour cannot anticipate the user's goal.

## How it differs from a fixed product tour

| Capability | Skilly for Builders | Fixed product tour |
| --- | --- | --- |
| Interaction | User asks a question in natural language | User follows a predefined sequence |
| Guidance | Spoken answer, answer history, and movable pointer | Tooltip, modal, or hotspot |
| Sequence | Adapts to the user's question | Authored in advance |
| Knowledge | Grounded in the team's published project skill | Stored in the tour steps |
| Installation | Script-tag widget | Vendor-specific web SDK or script |

## Setup

1. Create a project in Studio.
2. Add a website URL, documentation, or notes.
3. Review and edit the generated project skill.
4. Add and verify the domains where the widget may run.
5. Preview the assistant and publish the script tag.
