# Skilly for People

> Skilly for People is a voice-first AI tutor for Mac applications and websites. A user asks a question out loud, receives a spoken answer and live transcript, and watches Skilly point at the exact button, menu, or control to use next.

- Product type: Voice-first, screen-aware AI tutor
- Audience: People learning software and completing unfamiliar workflows
- macOS requirement: macOS 14.0 or later
- Mac download: https://github.com/tryskilly/skilly/releases/latest/download/Skilly.dmg
- Product page: https://tryskilly.app/people/
- Pricing: https://tryskilly.app/pricing.md

## What it does

Skilly for People listens while a live tutoring session is active, uses the current screen as context, answers out loud, streams the answer as text, and points at the relevant interface element. It can guide a user inside Mac applications without requiring a prebuilt skill for basic questions.

Optional SKILL.md files add current documentation, interface vocabulary, structured lessons, completion signals, and curricula for a specific application or workflow.

## How it works on Mac

1. Open the application where help is needed.
2. Hold Control+Option and ask a question, or enable Live Tutor for hands-free activation.
3. Skilly answers out loud and displays a live transcript.
4. Its pointer moves to the interface element associated with the answer.
5. The conversation history remains available for reviewing earlier guidance.

## Browser extensions

Skilly also provides voice-and-pointer guidance on websites through browser extensions:

- [Google Chrome](https://chromewebstore.google.com/detail/bgcapjmpidlhedeeefiikkiphjmdepoh)
- [Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/hdekoeononcjgmfkmbdomgmdglomakfk)
- [Mozilla Firefox](https://addons.mozilla.org/en-US/firefox/addon/skilly/)

Custom SKILL.md files import into the Mac application. The browser extensions provide immediate guidance on webpages without importing a generated skill file.
